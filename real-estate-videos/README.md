# Real Estate Videos

Home base for real estate video production — briefs, scripts, AI video prompts, and finished cuts.

> **Status:** staged here until the standalone `real-estate-videos` GitHub repo is created. Once it exists, this folder's contents move there as the repo root.

## Structure

- `briefs/` — one file per project: property/listing details, goal, target platform, deadline.
- `scripts/` — shot lists, voiceover lines, on-screen supers.
- `prompts/` — AI video generation prompts (Kling primary, Higgsfield secondary). Keep motion settings medium-low for controlled outputs.
- `assets/` — source footage, stills, logos, fonts, music references.
- `exports/` — final cuts and platform-specific versions (Reels 9:16, feed 1:1, etc.).

## Workflow

1. Drop a brief in `briefs/`.
2. Script + shot list in `scripts/`, iterate hooks and CTAs first.
3. Generate shots (prompts saved in `prompts/` so winning ones are reusable).
4. Cut, add supers + CTA, export to `exports/`.

## Creative ground rules

- Every video needs on-screen text (assume muted viewing) and a clear CTA.
- Brand/offer appears early, not in the last 3 seconds.
- No real people's likenesses without permission.
