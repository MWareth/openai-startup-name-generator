## Art direction note
Floareá's own palette is **bronze/gold + sage green against a pastel cream sky** — the
brochure's line is "A Life Painted in Pastel Horizons." That is lighter and warmer than the
dark cinematic treatment on the reference slides. Two options: keep the dark overlay across
all three projects for deck cohesion, or let each project carry its own palette and hold
cohesion through layout alone. Recommend the former — consistency beats per-project
fidelity when the client is comparing.
